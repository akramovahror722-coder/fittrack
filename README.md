# FitTrack

Boshlovchilar uchun mashq dasturlari, taymer, jurnal va haftalik natija grafigi.

## Imkoniyatlar

- 3 ta mashq dasturi va 30+ harakat
- Ish/dam olish taymeri va ovozli signal
- Kundalik mashq jurnali va statistika
- Haftalik natija grafigi (SVG)
- Natijalar `localStorage`da saqlanadi
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

React · TypeScript · Vite · Tailwind CSS · localStorage · SVG

## Ishga tushirish

```bash
npm install
npm run dev
```
